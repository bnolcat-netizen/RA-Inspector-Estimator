# RoofEstimate AI - Project Overview

## Problem Statement
A roofing business owner spends an excessive amount of time on a three-step manual process:
1. Taking photos of roofs on-site
2. Manually annotating images with required services/damage
3. Generating detailed, professional estimate documents for clients

The goal is to automate this workflow using AI image analysis, reducing hours of work to minutes.

## Target User
- Primary: A single roofing business owner (initial client)
- Future: Other roofing contractors (SaaS product)

## Core Value Proposition
A mobile-friendly web app that takes a batch of uploaded roof photos and produces a branded, professional PDF estimate document with annotated images and line items - with minimal manual effort from the contractor.

## Key Workflow
```
Photo capture → AI analysis → Contractor review/edit → PDF estimate generation
```

## What Makes This Different from Existing Tools
Most existing tools (RoofHawk, IMGING, EagleView, ARIS Detect) focus on:
- Storm/hail damage for insurance claims
- Damage detection only, not general servicing needs

This product focuses on:
- General roofing service needs (improper installation, maintenance, wear)
- Contractor workflow: inspect-to-quote in one pipeline
- Estimate document generation as a first-class feature
